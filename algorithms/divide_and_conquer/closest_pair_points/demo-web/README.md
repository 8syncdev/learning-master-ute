# Closest Pair · Step-by-step demo

React + Vite demo để trình chiếu thuật toán **Closest Pair of Points**.

## Chạy

\`\`\`bash
npm install
npm run dev
\`\`\`

## Build

\`\`\`bash
npm run build
\`\`\`

## Phím tắt

- \`←\` / \`→\`: chuyển bước
- \`Space\`: tự chạy / dừng
- \`F\`: toàn màn hình
- \`N\`: ẩn / hiện lời thoại
- \`R\`: về bước đầu
